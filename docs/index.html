02 The problem

Dependabot bumps the version
and leaves you with a red build.

The bump is the easy half. The hard half is the twenty call sites that used the old signature, the changelog nobody read, and the afternoon you lose to a stack trace before finding out that an argument quietly became required.

Patchery does the hard half — and then proves it did it. Because an agent told to “make the tests pass” can always just delete the tests.

03 One run, five gates

Nothing here
is taken on trust.

  1. 01Run the testsIs it actually broken?
  2. 02Run the agentRead the changelog, migrate the call sites.
  3. 03Check with gitWhat actually changed on disk?
  4. 04Run the tests againMeasure it. Don’t ask it.
  5. 05Open a PROnly if 01–04 came back clean.
04 The guard

    06 Install

    One file in,
    one workflow out.

    1. 01Add ANTHROPIC_AUTH_TOKEN under Settings → Secrets and variables → Actions.
    2. 02Save this as .github/workflows/self-maintain.yml.
    3. 03Actions → self-maintain → Run workflow. You choose the package.

    No scheduler, no background scanning, no repo-wide crawl in v0 — you point it at one package at a time, on purpose.

    Full setup guide
    yaml .github/workflows/self-maintain.yml 
    name: self-maintain

on:
  workflow_dispatch:
    inputs:
      package:      { required: true }
      target-dir:   { default: "." }
      test-command: { default: "npm test" }

permissions:
  contents: write
  pull-requests: write

jobs:
  fix:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      - run: npm ci
        working-directory: ${{ inputs.target-dir }}

      - id: sma
        uses: patchery-dev/Patchery@v0
        with:
          package:              ${{ inputs.package }}
          target-dir:           ${{ inputs.target-dir }}
          test-command:         ${{ inputs.test-command }}
          anthropic-auth-token: ${{ secrets.ANTHROPIC_AUTH_TOKEN }}

      - if: steps.sma.outputs.changed == 'true'
        uses: peter-evans/create-pull-request@v7
        with:
          branch:    self-maintain/${{ inputs.package }}
          body-path: ${{ steps.sma.outputs.pr-body-file }}
          add-paths: ${{ steps.sma.outputs.files }}
    07 Where this actually is

    We’d rather you audit us
    than trust us.

    True today

    • A GitHub Action you can install right now, MIT licensed.
    • One live pull request opened end to end with no human in the loop.
    • The guard is pure, unit-tested, and runs offline on every push.
    • Secrets are redacted before anything reaches a log or a PR body.
    • Works on Node / npm projects; the test command is yours to set.

    Not yet

    • No hosted service. You run it in your own Actions runner.
    • No paying customers, no user count, nothing to build a logo wall from.
    • No merged open-source pull request yet — three are open.
    • One package per run. Cascading breakages are not resolved.
    • Ecosystems beyond Node / npm are plausible but unverified.

    Every number on this page comes from a run you can open and read. The agent sees your source, so check your model provider’s data policy before pointing it at a private repository. Limitations, stated honestly →
